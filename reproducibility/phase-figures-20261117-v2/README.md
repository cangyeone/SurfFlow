# SurfFlow phase figures — fixed presentation record v2

Six main figures and four supplementary figures for the regional fundamental-mode Rayleigh phase-velocity study, 17 November 2026. This companion preserves the current figure inputs, scripts, vector figures and numerical verification. It does not replace the core inference/results record:
https://github.com/cangyeone/SurfFlow/releases/tag/phase-20261117-v1

## Replot
From this directory, in an environment with the dependencies below:
```
python tools/build_redesigned_figures_20261117.py
python tools/package_figure_review_20261117.py
```
The first command writes all ten figures (PDF, PNG and preview) and captions; the second verifies 27 frozen numerical summaries and assembles the 10-page `figure_review_20261117.pdf`. No neural inference, forward calculation, Monte Carlo run, training or network download is required to replot. The compact input NPZ files are hash-checked by the plotting script. `SHA256.json` records all shipped files (before replotting). PDF byte hashes can change with generation timestamps; numerical checks are the reproducibility criterion.

Tested environment: Python 3.12.12; numpy 2.4.2; scipy 1.17.0; pandas 3.0.1; matplotlib 3.10.8; cartopy 0.25.0; xarray 2026.4.0; pypdf 6.12.2; netCDF4. No package installation is performed by these scripts.

## Provenance and scope
The input manifests identify saved samples and source hashes. `figure_data.npz` combines existing regional and reference summaries with two synthetic display replays from frozen checkpoints. `presentation_context.npz` adds already-computed prior and error-scale results, with no new inference. The export scripts document their original server paths and are not portable experiment launchers. For checkpoint replay and the full published-scale reference chains, use the v1 core release; no new training or reference calculations were performed for this presentation revision.

Full-dimension posterior accuracy, universal Flow superiority and calibrated uncertainty at every real location are not claimed. The 17-period shallow-average coverage limitation and the 96-degree residual mismatch remain visible. Posterior profile means and regional/dispersion medians are distinguished in the captions. The source CSRM structural model provides context, not independent truth; local inversions are juxtaposed, not spatially jointly sampled.

## Geographic background
The small GMT Earth Relief crop is for map context only; `map_source.json` records its source and SHA256. Cite Tozer et al. (2019), DOI:10.1029/2019EA000658. The bundled 110m coastline is Natural Earth public-domain data (https://www.naturalearthdata.com/about/terms-of-use/), included to avoid a runtime download. The source and frozen CSRM Moho table are identified in the core release and manuscript.
